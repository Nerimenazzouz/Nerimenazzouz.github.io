Feb – Aug 2026 · DRÄXLMAIER Group · Sousse Hub

Intelligent Waste Management System

Waste evacuation across DRÄXLMAIER's industrial sites relied on paper forms and emails. I designed and built a digital platform that automates the full request lifecycle, then added an AI layer that answers questions about the data, analyzes it with machine learning and reads incoming documents automatically.

1. Digital platform

Power Apps application with a multi-step approval workflow, automatic notifications in Power Automate and document management in SharePoint. Power BI dashboards track waste by site, category, danger level, asset type, quantity and volume over time.

2. RAG assistant

Answers questions about approvals, waste volumes, request statuses and rejection reasons. Data is chunked, embedded with nomic-embed-text and stored in ChromaDB. LangChain sends the most relevant chunks with a rules prompt to Llama 3.2 on Ollama, so answers come from real data. It is read-only, hides personal information and resists prompt injection. Served by FastAPI in Docker.

3. Machine learning and analytics

Four scikit-learn models. Two TF-IDF and Logistic Regression classifiers label waste as Danger or No Danger and as Asset or Non-Asset. An Isolation Forest flags abnormal monthly volumes per site and category. K-Means groups sites by waste profile. pandas analytics measure step durations, request statistics and rejection causes.

4. Document recognition

Reads Waste Lists and invoices in Excel, PDF or image format. Text is extracted with pandas, pypdf or Tesseract OCR, structured into JSON by the language model and stored in a cumulative log.
